# Sprig 0.5.5

- **自动同步并推送。** 分支的上游与 Git 默认推送目标一致且推送地址唯一时，点击「推送」即可同步。分叉时默认自动 Merge，之前保存的 Rebase 选择也会生效。遇到冲突会暂停。首次推送或目标不明确时，请选择远端和分支。
- **提交并推送只需确认一次。** 确认窗口会显示已配置的推送目标和同步方式。确认后如果上游或地址发生变化，已创建的本地提交会保留，推送会停止。
- **二进制文件可照常提交和推送。** 提交确认读取暂存文件清单和检查结果。文件没有文本预览或差异超过预览上限时，仍可提交已暂存的内容。

99 项原生测试和 3 项发布脚本测试覆盖自动合并、远端变化、二进制字节完整性和未暂存修改保留。

## 安装与更新

提供 Apple Silicon 和 Intel 通用版，最低支持 macOS 13。已安装用户可通过 **Sprig → 检查更新…** 升级。首次安装可下载本页的 DMG 或 ZIP。

应用采用 ad-hoc 签名。更新 ZIP 和版本清单使用 Ed25519 签名校验。
