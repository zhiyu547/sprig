# Sprig 0.5.3

## 修复 DeepSeek 多文件提交生成失败

- 使用 DeepSeek 官方接口生成提交说明时，显式关闭默认思考模式，避免 4096 个输出 Token 全用于思考、最终正文为空而导致分段失败。
- 非思考模式覆盖单次生成、逐段分析、中间整理和最终汇总，适配 `deepseek-flash`、`deepseek-v4-pro` 及官方支持的 Flash 旧别名。
- 补充 45 个文件、约 352 KB、4 段分析及最终汇总的模拟回归测试，验证完整差异均被发送并汇总。

## 安装与更新

提供 Apple Silicon / Intel 通用版，最低 macOS 13。已安装用户可通过 **Sprig → 检查更新…** 升级，也可下载本页 DMG 或 ZIP。

应用仍采用 ad-hoc 签名，尚未 Apple Developer ID 签名／公证；更新 ZIP 与版本清单均使用独立 Ed25519 签名校验。
