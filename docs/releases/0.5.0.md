# Sprig 0.5.0

## 更清晰的工作区

- 仓库、分支、提交／历史／储藏／控制台集中在一排导航，常用同步操作就在右侧。
- 统一按钮、筛选器和图标的尺寸、留白与悬停反馈，扩大图标点击区域。
- 优化提交区、差异视图的文字层级、代码字号和增删颜色，保留可拖动分栏及布局记忆。
- 刷新按钮和 ⌘R 显示读取进度、完成时间或失败状态；刷新会重新读取本地文件、暂存状态和分支，保留当前草稿与有效选中项。

## 大批量改动也能生成 AI 提交说明

- 移除原来的 160 KB 限制：过滤后的暂存差异支持最多 **2 MB**，不按文件数量限制。
- 大于约 96 KB 的差异自动分段分析，再汇总成“Conventional Commits 标题 + 精简改动列表”；不需要为了生成说明手动拆成多个提交。
- 发送前展示总大小和分段数量，可翻页查看全部差异；生成时显示分析、整理和汇总进度，支持取消。
- 保留文件排除、敏感值遮盖与暂存快照校验。任何分段失败、超时或输出截断都会停止，原提交草稿保留。
- AI 代码审查按段展示结果，并明确提示跨段、跨文件关联的检查边界。

分段会多次调用你配置的 AI 服务，耗时与用量随改动增加。每次请求最多等待 90 秒，整次分批处理最多等待 10 分钟。文本均会发送分析，但摘要仍可能遗漏细节，使用前请核对。

## 验证与更新

- 71 项原生测试与 3 项发布脚本测试，覆盖分段完整性、多轮汇总、取消、超时、失败保护与手动刷新。
- 本机模拟 AI 完成 30 个文件、约 391 KB 差异的 5 段分析与最终汇总，并验证结果写入提交框；这不代表已验证所有第三方模型。
- 提供 Apple Silicon / Intel 通用版，最低 macOS 13。已安装 0.4.x 的用户可通过 **Sprig → 检查更新…** 安装，也可下载本页 DMG 或 ZIP。

应用仍采用 ad-hoc 签名，尚未 Apple Developer ID 签名／公证；更新 ZIP 与版本清单均使用独立 Ed25519 签名校验。
