# Sprig 0.5.4

## 改善大文件与慢速网络推送

- 网络命令不再受固定 120 秒截止限制，改为连续 10 分钟没有输出或总时长达到 2 小时后停止，避免正常长传输被过早中断。
- 推送与获取显示当前阶段的进度、传输量、速率和耗时，并提供取消按钮。快进拉取显示进度，但由于包含本地文件更新，不提供中途取消。
- 取消和超时会终止本次 Git 及同一进程组中的传输子进程，并限制管道收尾等待。同步推送正在合并或恢复修改时，会先完成当前本地阶段，再停止后续传输并保留恢复记录。
- 网络进度日志采用末尾 64 KB 滚动保留，不再因日志过多而中断推送；本地内容预览仍保留大小限制。

## 验证

95 项原生测试和 3 项发布脚本测试通过，覆盖子进程清理、进度更新、取消后的提交与草稿保护，以及同步恢复。另以 500 MB 隔离本地仓库进行带人为延迟的推送验证，141 秒成功完成，超过旧的 120 秒截止；这不是 HTTPS 上传速度基准。

## 安装与更新

提供 Apple Silicon / Intel 通用版，最低 macOS 13。已安装用户可通过 **Sprig → 检查更新…** 升级，也可下载本页 DMG 或 ZIP。

应用仍采用 ad-hoc 签名，尚未 Apple Developer ID 签名／公证；更新 ZIP 与版本清单均使用独立 Ed25519 签名校验。
