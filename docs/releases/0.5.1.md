# Sprig 0.5.1

## 新图标，更简洁的操作入口

- 全新黑白图标：暖白底板搭配黑色徽记，以负形呈现 Git 分支和提交节点。应用图标与项目主页同步更新。
- 统一仓库入口：通过左上角仓库下拉打开或切换项目，移除右上角重复的文件夹按钮；保留 ⌘O 快捷键。
- 统一设置入口：保留右上角设置按钮，移除提交区重复的齿轮；保留 ⌘, 快捷键。
- 提交区保留 AI 生成、提交说明历史、检查、提交及提交并推送，减少视觉干扰。

## 安装与更新

提供 Apple Silicon / Intel 通用版，最低 macOS 13。已安装用户可通过 **Sprig → 检查更新…** 升级，也可下载本页 DMG 或 ZIP。

应用仍采用 ad-hoc 签名，尚未 Apple Developer ID 签名／公证；更新 ZIP 与版本清单均使用独立 Ed25519 签名校验。
