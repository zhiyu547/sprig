# Sprig 0.4.1

## 修复与改进

- 新文件勾选、取消勾选或整组暂存后，保持在“未进行版本管理的文件”分组，不再跳入上方“更改”；刷新和重新打开仓库后保持一致。
- 新文件名和状态标记使用柔和红色，路径仍为灰色，复选框继续显示实际暂存状态。
- 已提交文件的后续修改归入“更改”；冲突和已有文件重命名继续保留原有处理方式。

勾选仍会将内容加入 Git 暂存区，AI 生成和提交继续以真实暂存内容为准。在“已暂存”或“工作区”筛选下，文件仍会随其实际状态显示或隐藏。

## 更新

0.4.0 用户可通过“Sprig → 检查更新”安装。也可从本页下载通用版 DMG 或 ZIP，支持 Apple Silicon 与 Intel、macOS 13 及以上。

应用仍使用 ad-hoc 签名，尚未 Apple Developer ID 签名／公证；自动更新包与清单均使用独立 Ed25519 签名校验。
