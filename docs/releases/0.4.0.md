# Sprig 0.4.0

首个公开源码发行版。轻量原生 macOS Git 提交工作台。

## 新增

- 独立“关于 Sprig”窗口：版本、更新开关、许可；菜单保留“检查更新”。
- Sparkle 更新包及版本清单签名验证，确认后下载、安装并重启。
- 正在执行 Git 操作、AI 请求或打开应用对话框时，等待结束后再安装。
- Apple Silicon 与 Intel 通用应用包。
- Copyright © 2026 zhiyu、应用内许可入口及完整第三方声明。

## 已有功能

- 更改和未跟踪文件分组、暂存／取消暂存、并排／统一 Diff。
- 可拖动的左右分栏和提交编辑区域，自动保留尺寸。
- 提交、修正、提交并推送；推送前自动 Merge／Rebase 及冲突暂停恢复。
- 分支、标签、历史、储藏、Cherry-pick／Revert。
- AI 提交说明与审查、发送范围预览、敏感内容过滤、Keychain 密钥保存。

## 安装与许可

macOS 13 或更高版本，需要系统 Git。Apple Silicon 与 Intel 均包含在安装包中；Intel 与较早 macOS 版本仍需更多实机验证。

此版本采用 ad-hoc 签名，尚未 Apple Developer ID 签名／公证。首次安装可能出现开发者验证提示；确认下载来源后按 macOS 隐私与安全性页面的提示处理。

0.3.x 尚未包含更新器，需手动安装本版一次。之后可从应用内检查更新。
