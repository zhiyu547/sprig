# Sprig 0.5.2

## AI 提交说明修复与优化

- 修复 AI 分段处理失败时的误导提示：模型因长度限制停止且正文为空时，现在明确显示输出截断及可用的 Token 用量，便于定位问题。
- 区分仅返回思考内容、内容过滤、拒绝响应、工具调用、空正文与格式不兼容；失败时保留原草稿，不采用思考过程或不完整结果。
- 对已识别的阿里云百炼千问混合思考型号，生成提交说明及分段分析、汇总时关闭深度思考，减少等待；代码审查继续使用服务默认行为。
- 兼容以文本内容块数组返回的最终正文，避免把包含不支持内容块的部分文本当作完整结果。

## 安装与更新

提供 Apple Silicon / Intel 通用版，最低 macOS 13。已安装用户可通过 **Sprig → 检查更新…** 升级，也可下载本页 DMG 或 ZIP。

应用仍采用 ad-hoc 签名，尚未 Apple Developer ID 签名／公证；更新 ZIP 与版本清单均使用独立 Ed25519 签名校验。
