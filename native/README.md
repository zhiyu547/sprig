# Sprig · macOS 原生版 0.4.0

SwiftUI + AppKit 界面，系统 `/usr/bin/git`，通过 Sparkle 2.10.0 提供自动更新。真实读写本地仓库。

## 打开与使用

打开 `build/Sprig.app`，选择已有 Git 仓库或子目录，也可拖入文件夹。界面顶部显示仓库、分支、Fetch、Pull、Push 和设置。

1. 在“更改”或“未进行版本管理的文件”中查看 Diff。点击分组三角周围、标题文字或右侧空白可展开／折叠；复选框只控制暂存。“未进行版本管理的文件”数量为 0 时隐藏，有未跟踪文件时自动显示。
2. **勾选即暂存**该文件当前全部修改；取消勾选保留工作区内容。标记“部分”的文件包含已暂存和未暂存两份差异，直接提交只使用已暂存部分。
3. 填写提交说明，或点击编辑框上方的薄荷绿色星光图标进行 AI 生成；“检查”菜单提供本地检查和 AI 审查。
4. 点击“提交”或“提交并推送”，核对文件范围和说明后确认。Git hooks 正常执行。
5. 提交并推送分两步：本地提交成功后确认远端和目标分支。推送失败可以单独重试，不会重复创建提交。

恢复工作区修改、删除分支/储藏等操作都有明确确认。恢复文件只影响未暂存内容；操作前复核变化，包括二进制内容。合并、变基、Cherry-pick、Revert 要求工作区干净；发生冲突后在外部编辑器解决，底栏可继续/中止。

### 自动同步并推送

- 推送确认默认开启“推送前自动同步远端更新”。Merge / Rebase 按仓库记忆，默认 Merge。关闭该选项执行普通推送。
- 获取所选远端的实际 push URL 和目标分支；仅本地领先直接推送，仅落后则快进，分叉时使用所选方式整合。Merge 保留原提交并增加合并提交；Rebase 重放本地提交，改变提交 ID。
- 整合前自动储藏暂存、未暂存和未跟踪文件，整合后用 `stash apply --index` 恢复，成功恢复后才推送。部分暂存内容不会被意外加入合并提交；忽略文件不储藏。子模块修改需自行处理。
- Merge / Rebase 冲突时暂停。在外部编辑器处理后，右键冲突文件选择“标记为已解决”，再点击底栏“继续同步并推送”；“取消同步”中止正在进行的整合并恢复自动储藏，已完成的提交不回滚。
- 恢复储藏也可能冲突，或应用可能在恢复过程中退出。此时不自动重复套用储藏，需人工核对工作区和暂存区后点击“恢复已核对，继续”。自动储藏副本会保留供再次核对。
- 同步状态写入当前 worktree 的 Git 目录，重新打开仓库后恢复入口仍在。分支/HEAD/目标地址被外部改变时停止，取消任务保留代码和未恢复的储藏。
- 获取更新后远端再次变化时最多自动重试两次；认证、网络、hook 和分支保护拒绝直接报错，允许单独重试，不重复创建业务提交。不执行强制推送，不自动推送其他分支或标签。
- 当前自动同步要求本地分支、唯一 push URL 与可用共同祖先；多推送地址、浅克隆缺失祖先、三方冲突编辑器暂不自动处理。

### 分支、历史与储藏

- 顶部点击分支：搜索、本地/远程/标签分组、新建与切换；右键分支可合并、变基或安全删除已合并本地分支。检出标签会进入分离 HEAD。
- “历史”：每页 50 条，按说明/哈希或作者检索，可选全部分支；选择提交后查看说明和逐文件差异。右键可从此提交建立分支/标签、Cherry-pick、Revert。合并提交按第一父提交比较。
- “储藏”：Git Stash，可包含未跟踪文件；恢复时还原原有暂存状态，保留储藏记录。
- “控制台”：本次运行最近 40 次操作结果和错误。

### AI 配置

⌘, 打开设置，填写服务商提供的 **API 基础地址**（通常含 `/v1`）、**模型 ID**、**API Key**。也支持直接填写以 `/chat/completions` 结尾的完整地址。本机 Ollama 可填写 `http://localhost:11434/v1`，前提是本机已安装并提供兼容接口；Sprig 不附带或下载模型。

- 远程地址要求 HTTPS；仅 localhost/127.0.0.1/::1 允许 HTTP。拒绝重定向。
- Key 存 macOS 钥匙串，按接口地址隔离；设置页留空保留原密钥，独立按钮删除，切换服务不会搬运密钥。
- 默认使用 `max_tokens`；服务要求时可切换为 `max_completion_tokens`。其他专有认证或 API 格式暂不支持。
- 仅发送已暂存文本。发送前显示目标接口、模型、文件名单和实际 Diff；工作区未暂存修改不会发出。
- 每行一条排除规则，按路径片段不区分大小写匹配。默认排除常见凭据文件、密钥、锁文件；匹配到的单行敏感配置在本机遮盖后继续分析其余差异；私钥、无法可靠脱敏的多行值和二进制仍排除。预览逐项列出脱敏文件、排除原因；全部排除时可直接进入排除设置。自动检查不保证发现所有敏感内容，发送预览用于人工核对。
- 单次差异上限 160 KB、响应上限 1 MB、请求超时 90 秒，支持取消。过大或截断结果明确报错并保留草稿。
- 提交说明采用一行 Conventional Commits 标题，空行后用短横线列出关键改动。简单变更只写 1–3 条，不强制凑数；不添加影响/验证章节，不罗列未变化项、长路径或完整端点。覆盖范围和脱敏提示显示在结果界面，AI 审查仍输出风险与验证建议。
- 结果可编辑，再点击“使用此说明”；期间暂存内容变化会拒绝替换草稿。之后再次改变暂存范围，提交确认会提示重新核对 AI 草稿。

当前已验证请求格式、解析、模拟 HTTP 传输、排除规则和暂存范围；尚未连接用户真实 AI 服务。需自行填入有效服务配置后使用。

### 提交设置

支持作者覆盖、Signed-off-by、空白问题阻止提交、TODO/FIXME 清单，以及保存当前仓库的 Git 姓名/邮箱。格式化、语言级分析、依赖扫描等通过项目已有 hooks 接入，不声称运行了 IDEA 自身的检查器。

### 快捷键

| 快捷键 | 操作 |
| --- | --- |
| ⌘O / ⌘R | 打开仓库 / 刷新 |
| ⌘K / ⇧⌘K | 提交 / 提交并推送 |
| ⌘L / ⌘, | 历史 / 设置 |
| ⌥⌘[ / ⌥⌘] | 扩大代码区 / 扩大文件列表，每次 24 pt |
| ⌥⌘0 | 恢复默认分栏宽度 340 pt |
| ⌘W / ⌘Q | 关闭窗口 / 退出；Git 操作进行中需等待完成 |

左右分栏可鼠标拖动、记忆宽度、双击恢复。文件列表与提交区之间的横线也可上下拖动，提交信息框随之增高／缩小；记忆提交区高度，双击横线恢复默认 320 pt。保留文件列表和提交按钮所需空间，窗口临时缩小时限制高度，放大后恢复用户设置；并排 Diff 同步纵向滚动，两侧独立横向滚动。

## 构建和测试

需要已配置并接受许可的 Xcode 工具链。在本目录运行：

```sh
swift test
swift build -c release --product GitTool --arch arm64 --arch x86_64
python3 scripts/package_app.py --arch universal
```

产物为 `build/Sprig.app`、`build/release/0.4.0/Sprig-0.4.0-macos-universal.zip`。打包脚本使用 sips/iconutil 生成原生 ICNS，然后进行 ad-hoc 签名。编译目标保留 `GitTool` 名称，应用名称显示 Sprig；沿用 `cn.gittool.native` 保存早期仓库记录和分栏偏好。

57 项原生测试及 3 项发布脚本测试在临时目录创建隔离仓库，覆盖部分暂存、首次提交、修正、签署、hooks、并发 index 锁、过期确认、空白检查、分支、标签、历史、重命名、储藏、Revert、二进制恢复保护，以及 AI 请求/模拟传输/响应与排除范围、超时和取消、窗口与分栏布局稳定性、刷新期间代码像素连续性与滚动位置保留。自动同步使用本地裸仓库和两个工作副本，验证 Merge、Rebase、快进、冲突继续/中止、重启恢复、部分暂存与未跟踪文件保护、忽略文件防覆盖、储藏恢复冲突、独立 push URL/分支、并发更新重试上限和服务器拒绝后的独立重试。

交互验证夹具：

```sh
python3 scripts/create_sprig_qa_repository.py
```

仅创建 `build/SprigQARepository` 和本机裸仓库 `build/SprigQARemote.git`；已存在则保留，不使用业务仓库。旧的 `create_qa_repository.py`、`benchmark.py` 和 `measure_idle.py` 保留作读取与资源基准。测量报告中 RSS 指 ps 常驻内存，不等于活动监视器物理内存。

## 当前边界

- 构建包含 Apple Silicon 和 Intel；最低部署 macOS 13，实测 Apple Silicon / macOS 27。Intel 和较早 macOS 尚需实机验证。
- 本地产物为 ad-hoc 签名；尚未 Developer ID 签名、公证；0.4.0 已集成 Sparkle 签名更新。
- 文件级暂存已实现，尚无逐行暂存、三方冲突编辑、交互式 Rebase、完整拓扑图、Clone/远端配置界面等；
- 网络认证沿用系统 Git/SSH 与凭据配置。没有交互式终端密码框；须先配置可用的凭据/SSH agent。
- 二进制及非 UTF-8 内容不作文本预览；非 UTF-8 文件名明确报错。单次 Git 输出 4 MB，状态 8 MB，未跟踪预览 2 MB；超过 20,000 行跳过渲染。
- 提交准备读取完整暂存 Diff；极大提交超过读取上限时需缩小范围或使用外部工具。基本语法高亮用于阅读，不是完整编辑器。
- Git 操作默认 15 秒，提交/网络/整合最长 120 秒。超时结果需核实历史；复杂 hook/过滤器派生进程生命周期与系统强制退出仍需进一步验证。
- 读取状态与 Diff 为最终一致预览；提交使用已审核 index 快照、实际 index 锁、私有暂存副本和提交前校验。应用内串行写操作，保留外部已有暂存。

## 版本更新与许可

通过 Sprig 菜单或“关于 Sprig”中的“检查更新”获取版本信息。每日自动检查可在“关于 Sprig”关闭；确认后安装，繁忙操作或打开的应用对话框会推迟重启。原 0.3.x 需手动安装本版一次。
